# Issue Tracker

Work is tracked as local Markdown user stories under `docs/user-stories/`.

## Read work

Start with `docs/user-stories/INDEX.md`. Each entry links to its detailed story file. An unchecked index item is open; a checked item is complete.

Read the linked story before planning, triaging, specifying, or implementing it. The story contains its acceptance criteria, dependencies, implementation notes, and status.

## Create work

Create a story beside the existing files using `docs/user-stories/00-TEMPLATE.md`. Follow the existing numeric filename and user-story ID conventions. Add the story to `docs/user-stories/INDEX.md` as an unchecked item.

## Update work

Keep the story's status and acceptance-criteria checkboxes current. When the story is complete, mark its index entry checked. Do not create GitHub issues for work tracked here.

## Triage

Record a story's triage label as `**Triage:** <label>` with its other metadata. Use the labels defined in `docs/agents/triage-labels.md`.
